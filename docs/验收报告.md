## 2. 复跑命令

```bash
# 全量（含构建、9 个 CTest 目标、全部验收脚本、压测）
bash scripts/acceptance.sh

# 跳过压测
SKIP_BENCH=1 bash scripts/acceptance.sh

# 复用已有构建
SKIP_BUILD=1 bash scripts/acceptance.sh

# Sanitizer
bash scripts/build-sanitize.sh
```

## 3. 回填要求

1. 记录 `git rev-parse --short HEAD`、执行日期、主机配置。
2. 每个脚本记录 PASS/FAIL 与失败项；压测记录 `bench_result` 原始行。
3. 未达标项按 R9 如实记录实测差距，不修改口径。
